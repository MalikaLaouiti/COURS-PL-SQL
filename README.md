# 🚀 SELECT * FROM PL/SQL;

### Learn SQL. Explore PL/SQL. Experience the code.

Et si apprendre PL/SQL devenait une expérience interactive plutôt qu'une simple lecture de cours ?

Nous sommes des étudiants ingénieurs passionnés par le développement et les nouvelles façons d'apprendre. Dans le cadre de notre workshop, nous avons décidé de mettre nos connaissances en pratique en imaginant une expérience pédagogique autour d'Oracle PL/SQL.

Notre idée ? Transformer un cours technique en un environnement immersif, interactif et accessible, où l'on peut explorer les concepts, comprendre leur fonctionnement et tester ses connaissances.

**Parce qu'apprendre à programmer ne devrait pas se limiter à lire du code. Il faut aussi expérimenter !**

---

## 💡 The Idea

Nous avons conçu une plateforme web qui propose une nouvelle manière de découvrir PL/SQL à travers une mindmap 3D interactive.

Au lieu de parcourir des pages de théorie, l'apprenant explore visuellement les différentes notions du cours. Chaque élément représente un concept PL/SQL et permet d'accéder à ses explications, ses exemples et ses exercices.

L'objectif est simple : rendre l'apprentissage plus vivant, favoriser la compréhension et encourager l'exploration.

## ✨ Features

- **🌐 Interactive 3D Mindmap** — Explorez les concepts PL/SQL dans un univers 3D dynamique.
- **📚 Learn by Exploring** — Découvrez les notions à travers des explications structurées et des exemples de code.
- **🧠 Knowledge Quiz** — Testez votre compréhension et obtenez un score pour évaluer vos acquis.
- **💬 Learning Assistant** — Posez vos questions sur le cours et obtenez des réponses basées sur les notions disponibles.
- **🎯 Interactive Experience** — Sélectionnez les tables, naviguez dans l'environnement 3D et découvrez les concepts à votre rythme.
- **📱 Responsive Design** — Profitez de l'expérience sur ordinateur, tablette et mobile.

## 🗄️ What Can You Explore?

La plateforme couvre plusieurs notions fondamentales de PL/SQL :

| Concept | Description |
|---|---|
| Blocks | Structure des blocs PL/SQL |
| Variables & Constants | Déclaration et manipulation |
| Conditions & Loops | Structures conditionnelles et répétitives |
| Procedures | Création de procédures |
| Functions | Fonctions et valeurs retournées |
| Cursors | Manipulation des résultats SQL |
| Triggers | Déclencheurs automatiques |
| Exceptions | Gestion des erreurs |
| Records & Collections | Structures de données |
| Packages | Organisation du code PL/SQL |

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate to the project
cd <project-folder>

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL displayed in your terminal to explore the application.
